# RK Restaurant

A static, GitHub Pages-ready website for RK Restaurant in Kakinada.

## Local images

Place the supplied restaurant photographs in `assets/images/` using these exact names:

- `hero-food.jpg`
- `special-biryani.jpg`
- `gidda-massore.jpg`
- `village-biryani.jpg`
- `abu-dhabi-fish.jpg`
- `chicken.jpg`
- `chicken-65.jpg`
- `basmati-biryani.jpg`
- `restaurant-interior.jpg`
- `restaurant-exterior.jpg`

Until then, the site displays designed placeholder blocks and never shows broken image icons.

## Updating the menu

Edit the `menuItems` array at the top of `js/script.js`. Prices intentionally use `Add price` because no restaurant menu prices were supplied.

## Run locally

Open `index.html` directly, or serve this folder with any static server. All asset references are relative and compatible with GitHub Pages.
